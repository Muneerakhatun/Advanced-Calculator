Advanced Calculator 🧮

About the Project

This is a command-line Advanced Calculator developed using Python. It performs basic mathematical operations and includes input validation and error handling.

Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Square Root
- Repeating menu using a while loop
- Division by zero protection
- Square root validation
- Invalid input handling
- Exit option

Technologies Used

- Python 3
- Visual Studio Code

How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Run "calculator.py".
